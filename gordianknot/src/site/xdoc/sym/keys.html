GordianKnot Symmetric Keys Tony Washer

Many objects in the Symmetric API are keyed objects, whereby a secret key is shared by both participants. These keys may be randomly generated, or else deterministically resolved from a password or agreement protocol

These keys are represented by a GordianKey object which can be passed in to the various APIs

When a key is no longer needed, it can be destroyed, whereby it is marked as destroyed, and its details are erased from memory. Once a key has been destroyed, it will be rejected by most API and objects that have been previously initialised with the newly destroyed key will be unuseable until re-initialised with a valid key.
